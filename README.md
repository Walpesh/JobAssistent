# 🤖 JobAssistant — Локальный карьерный ассистент

Полностью локальный инструмент для анализа вакансий и генерации сопроводительных писем.  
Работает на вашей видеокарте (RTX 3060+) через **Ollama + Qwen 2.5**.

---

## Возможности

- **Парсинг вакансий** с hh.ru (кастомный парсер) и любых других сайтов
- **Анализ совпадения** вашего профиля с требованиями вакансии (Hard / Soft / Formal skills)
- **Генерация сопроводительного письма** без клише и воды
- **История откликов** в SQLite
- **Системные логи** в реальном времени
- Всё работает **офлайн** (кроме загрузки страницы вакансии)

---

## Архитектура (Modular Flow)

```
app.py                      ← точка входа (оркестратор)
└── job_assistant/
    ├── config.py           ← константы, CSS, настройки Ollama
    ├── utils/
    │   └── logging.py      ← системные логи в session_state
    ├── db/
    │   └── database.py     ← SQLite (история чатов)
    ├── profile/
    │   └── loader.py       ← загрузка my_profile.docx
    ├── parser/
    │   └── hh_parser.py    ← парсер HH.ru + fallback
    ├── llm/
    │   └── client.py       ← промпт + стриминг Ollama
    └── ui/
        ├── sidebar.py      ← боковая панель + история
        ├── main_view.py    ← форма анализа / просмотр чата
        └── logs_panel.py   ← панель логов
```

Каждый модуль отвечает за один поток данных.  
`app.py` только связывает их в правильном порядке.

## Быстрый старт

### 1. Установите Ollama и модель

```bash
# https://ollama.com
ollama pull qwen2.5:14b-instruct
ollama serve          # должен слушать localhost:11434
```

### 2. Клонируйте / скопируйте проект

```bash
cd job_assistant_project
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Положите свой профиль

Создайте файл `my_profile.docx` рядом с `app.py` и заполните его:

- Опыт работы (конкретные факты, проекты, стек)
- Навыки
- Образование
- Достижения

Чем конкретнее — тем лучше письма.

### 5. Запустите

```bash
streamlit run app.py
```

Откроется браузер: `http://localhost:8501`

## Как пользоваться

1. **Вставьте ссылку** на вакансию hh.ru → «Загрузить текст по ссылке»  
   или вставьте текст вакансии вручную.
2. Нажмите **«Проанализировать и составить отклик»**.
3. Модель сгенерирует:
   - % совпадения + краткий анализ
   - Готовое сопроводительное письмо
4. Результат автоматически сохраняется в историю (сайдбар).
5. Можно вернуться к любому прошлому анализу или удалить его.

## Настройка модели

Все параметры Ollama находятся в `job_assistant/config.py`:

```python
OLLAMA_MODEL = "qwen2.5:14b-instruct"
OLLAMA_OPTIONS = {
    "temperature": 0.35,      # меньше креатива → точнее правила
    "top_p": 0.85,
    "top_k": 40,
    "repeat_penalty": 1.12,
    "num_ctx": 10000,
    "num_predict": 2500,
}
```

Можно заменить модель на любую другую, поддерживаемую Ollama.

## Логи

Внизу страницы есть раскрывающаяся панель **«Системный логгеры»**.  
Туда пишутся:

- запуск приложения
- парсинг URL
- ошибки Ollama / БД
- время генерации

## Fetcher v3.0 fix #2
- HH API 403 теперь явно считается ограничением API без токена; HTML fallback использует более устойчивые селекторы и JSON/URL-поиск карточек.
- HH удалённый поиск использует актуальный `work_format=REMOTE`.
- Список ключевых слов для HH преобразуется в OR-запрос, чтобы `Python, C#, Unity` не превращался в чрезмерно узкий поиск.
- RemoteOK больше не ограничивает выдачу первым словом, если задано несколько ключевых слов. Это позволяет искать C#/Unity и другие термины, а не только `python`.
- WWR RSS остаётся ограниченным текущей лентой: увеличение `max_pages` не создаёт новые страницы, поэтому после исчерпания RSS повторные проходы не маскируются под новый поиск.
